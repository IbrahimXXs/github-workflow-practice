# Branch and pull request practice

This repository is a sandbox for learning GitHub workflows.

1. Create a branch from `main` for one focused change.
2. Add or edit a documentation file and commit with a descriptive message.
3. Open a pull request targeting `main`.
4. Inspect the diff and confirm that only the intended files changed.
5. Merge the pull request when the change is ready.

Use small documentation changes here to practice without affecting production projects.
