# Issue lifecycle practice

Use this checklist when tracking work in this sandbox:

- Give the issue a specific, actionable title.
- Describe the expected outcome and how to verify it.
- Link the relevant pull request when a change is required.
- Confirm the expected outcome before closing the issue as completed.
- Reopen the issue if the original problem returns.

For a repository setup check, verify that the repository is accessible and its README explains its purpose.
