# Security reporting

Report suspected security problems privately to ibrahimsarraj1@gmail.com. Include the affected file, a minimal reproduction, and the expected impact. Do not send passwords, tokens, or private repository contents.

The tool currently fetches public metadata over HTTPS without authentication. It must not execute repository content or write to GitHub. Username validation should prevent user input from altering the API path or query.

Please avoid posting an exploit publicly before the report has been assessed. No response-time guarantee or bounty is offered.
