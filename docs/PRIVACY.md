# Privacy

Repository Summary queries public repository metadata directly from GitHub. The selected username and your network IP are visible to GitHub when requests are made.

The tool does not request credentials, access private repositories, modify GitHub data, or send data to analytics services. It prints results to your terminal and creates no report file unless you redirect output yourself.

Public metadata may include repository names, URLs, languages, and star/fork counts. Review exported reports before sharing them. Support messages sent to ibrahimsarraj1@gmail.com should omit tokens, passwords, and private project data.
